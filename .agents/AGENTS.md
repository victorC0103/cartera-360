# Reglas del Proyecto (CrediRuta ERP)

## Documentación Obligatoria (Changelog)
Actúa como un desarrollador disciplinado. Para este proyecto (CrediRuta ERP), es estrictamente necesario mantener un registro histórico de todas las modificaciones arquitectónicas y de código, ya que este proyecto tiene fines académicos (Tesis de Ingeniería).

A partir de este momento, **CADA VEZ** que completes una tarea, generes una nueva funcionalidad, corrijas un bug o modifiques la estructura de la base de datos, debes actualizar automáticamente el archivo `CHANGELOG.md` ubicado en la raíz del monorepo. Si el archivo no existe, créalo.

Debes utilizar el siguiente formato estricto en Markdown para documentar tus cambios:

## [Fecha en formato YYYY-MM-DD] - Título Breve de la Tarea
**Módulo Afectado:** [Backend / Frontend / Base de Datos / Infraestructura]

### 🚀 Añadido (Added)
- [Lista de nuevas características, endpoints, tablas o componentes creados]

### 🔄 Modificado (Changed)
- [Lista de cambios en la lógica existente, refactorizaciones o actualizaciones]

### 🐛 Corregido (Fixed)
- [Lista de errores solucionados]

### 📝 Notas Técnicas / Justificación Académica
- [Explica BREVEMENTE por qué tomaste una decisión técnica específica. Esto es vital para el documento de tesis].

---
**Regla de Ejecución:** Nunca termines una respuesta de código sin incluir el bloque de actualización del `CHANGELOG.md`.
